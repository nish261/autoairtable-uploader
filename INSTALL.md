# Quick Start

## Install (2 minutes)

### 1. Load Extension
1. Go to `chrome://extensions/`
2. Turn on "Developer mode" (top right)
3. Click "Load unpacked"
4. Select folder: `/Users/nishchalasri/Downloads/airtable-video-uploader`

### 2. Get API Key (one time)
1. Go to https://airtable.com/create/tokens
2. Click "Create new token"
3. Add scopes: `data.records:read` and `data.records:write`
4. Add your bases
5. Copy the token (pat...)

### 3. Save API Key
1. Click extension icon
2. Paste API key
3. Click "Save API Key"

## Use It

1. **Open your Airtable table** in Chrome
2. **Click extension** - it auto-detects your table
3. **Select videos** (up to 100)
4. **Click upload**
5. **Done!** New records created

## What It Does

- Creates 1 new record per video
- Random filenames? No problem!
- Just bulk upload and go

## Example

You have 50 videos with random names → Select all 50 → Upload → 50 new records created in your Airtable
